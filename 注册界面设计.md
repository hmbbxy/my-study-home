# 骨架
## 信息输入
1. 通过表格元素table来简单的排版。
2. 创建多个输入框
3. 限定输入内容的最大长度（属性maxlength="10"，就表示最多只能输入10个字的内容）
4. 空格转义字符（规范排版）
+ &nbsp;是空格转义字符，共6个字符，以&开头，分号;结尾。

其中，nbsp是Non-Breaking Space的缩写。

并且，每个&nbsp;就表示空一格，可以使用多个
```html
<tr>
    <td>密&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;码</td>
    <td><input type="password" placeholder="请输入9~16位密码"></td>
</tr>
```
5. 设置超链接
```html
 <a href="javascript:alert('发送成功')">点击发送验证码</a>
```
6. 设置信息选择
+ 设置下拉菜单
+ 设置单选按钮
7. 设置复选框
+ 因为商家注册协议内容复杂，我们这里不进行跳转。

在这里，我们将超链接的属性href="#"，表示我们点击超链接时，就在当前页面，不进行跳转

```html
<tr>
    <td></td>
    <td>
        <input type="checkbox">我已阅读并同意<a href="#">《商家注册协议》</a>
    </td>
</tr>
```
8. 信息提交按钮
9. 设置提交后的动作
10. 通过标题元素h创建一个标题
***
11. CSS添加样式，我们遵循先整体，再局部的思想
12. 将整体内容缩进一段距离，标题缩进的同时设置字体颜色和大小。
+ 因为表格元素table有两列，我们只需要它的第一列缩进就行。



所以，我们需要在每行的第一列的`<td>`标签内添加class属性，通过类选择器实现第一列的整体缩进。



这里，我们将class属性设置为class="first"

13. 设置单元格间距(属性border-spacing：用于设置相邻单元格边框之间的间距;它的属性值，使用数值加单位的形式，前面10px是横向间距，后面25px是纵向间距，中间以空格隔开)
14. 调整输入框的宽度，显示完整信息
+ 在标签后使用方括号[]来指定标签的属性信息
```html
 /* 使用属性选择器，设置包含属性type="text"的input元素样式 */
    input[type="text"] {
        width: 100%;
        line-height: 35px;
    }
```
15. 设置下拉菜单大小
```html
/* 使用标签选择器，设置下拉列表元素select的高度为40像素 */
    select {
        height: 40px;
    }
```
